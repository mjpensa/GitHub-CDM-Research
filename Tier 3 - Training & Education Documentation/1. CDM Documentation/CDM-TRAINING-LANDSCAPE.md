# CDM Training & Certification Landscape

**Date:** December 2025
**Classification:** Training Inventory

---

## Overview

This document provides a comprehensive inventory of available CDM training resources, courses, and certification programs. The training landscape has expanded significantly since CDM became an open standard under FINOS in 2023.

---

## Currently Available Training

### Free/Open Training

#### 1. Introduction to the Common Domain Model (CDM) - LFEL1016

| Attribute | Detail |
|-----------|--------|
| **Provider** | Linux Foundation (in partnership with FINOS) |
| **Course Code** | LFEL1016 |
| **Duration** | 90 minutes |
| **Cost** | Free |
| **Format** | Express Learning (self-paced) |
| **Level** | Introductory |
| **URL** | https://training.linuxfoundation.org/express-learning/introduction-to-the-common-domain-model-cdm-lfel1016/ |

**Description:**
Learn about the CDM—a model for financial products, trades, and trade lifecycle events, aligning data, systems, and processes. Available in multiple programming languages for cross-technology implementation.

**Target Audience:**
- Financial professionals in trading, operations, risk management, and compliance
- IT professionals and data architects
- Business analysts and consultants
- Anyone interested in financial data standardization

**Learning Outcomes:**
- Understand CDM significance, scope, and purpose
- Apply CDM in financial markets contexts
- Standardize data across derivatives, securities, and repos
- Apply business events to related transactions
- Create standardized, interoperable services leveraging CDM

**Development Partners:**
- Linux Foundation
- FINOS
- TradeHeader (co-creator of CDM, specialist training provider)

## Recommended Learning Paths

### Business Analyst Path

1. **Foundation:** LFEL1016 - Introduction to CDM (90 min)
2. **Applied:** CDM Collateral Start-up Guide
3. **Advanced:** Working Group participation (Collateral or Derivatives)

### Developer Path

1. **Foundation:** LFEL1016 - Introduction to CDM (90 min)
2. **Technical:** FINOS CDM GitHub repository exploration
3. **Hands-on:** CDM Starter project implementation
4. **Advanced:** Contribution to CDM open source

### Regulatory Specialist Path

1. **Foundation:** LFEL1016 - Introduction to CDM (90 min)
2. **Applied:** TradeHeader DRR FAQ and documentation
3. **Technical:** ISDA DRR InfoHub resources
4. **Advanced:** REGnosys Rosetta platform training

### Data Engineer Path

1. **Foundation:** LFEL1016 - Introduction to CDM (90 min)
2. **Technical:** CDM data model documentation
3. **Applied:** Code generators (rosetta-code-generators)
4. **Advanced:** Language-specific implementation (Python, Java)

## Certification Programs

### Currently Available

| Certification | Provider | Status |
|---------------|----------|--------|
| FINOS Certified FDC3 Practitioner (FCFP) | FINOS/Linux Foundation | Available |
| FINOS Open Source in Finance (FSOSD) | FINOS/Linux Foundation | Available |

**Note:** As of December 2025, there is no dedicated CDM-specific certification program. The LFEL1016 course provides a completion badge but not a formal certification.

### Gap: CDM-Specific Certification

The industry currently lacks:
- CDM Developer Certification
- CDM Implementation Specialist Certification
- DRR Implementation Certification
