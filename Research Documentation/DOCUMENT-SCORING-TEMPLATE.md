# CDM Research Document Scoring Template

**Purpose:** Systematic evaluation of documents for executive summary enrichment
**Created:** December 2025
**Target:** Identify high-value content to strengthen CDM/DRR adoption analysis

---

## Scoring Methodology

### Weighted Multi-Criteria Model (100 points max)

| Dimension | Weight | Max Points | Description |
|-----------|--------|------------|-------------|
| Strategic Relevance | 30% | 30 | Alignment with exec summary themes |
| Information Quality | 25% | 25 | Source credibility, specificity, data |
| Gap-Filling Potential | 20% | 20 | Addresses identified analysis gaps |
| Recency | 15% | 15 | Publication date (2025 preferred) |
| Uniqueness | 10% | 10 | Original vs. duplicate content |

---

## Dimension 1: Strategic Relevance (0-30 points)

**Score based on direct alignment with executive summary themes:**

| Points | Criteria | Examples |
|--------|----------|----------|
| 27-30 | Directly discusses US Tier 1 bank CDM strategies with specifics | JPMorgan webinar, bank architecture details |
| 24-26 | Production implementation evidence with metrics | JSCC case study, BNP deployment data |
| 21-23 | DRR adoption economics/benefits quantified | Capgemini Industry Perspectives |
| 18-20 | Regulatory drivers for CDM adoption | FDTA proposed rule, CFTC specs |
| 15-17 | Strategic integration approaches discussed | Architecture patterns, translation strategies |
| 12-14 | CDM technical capabilities relevant to strategy | Smart contracts, tokenization roadmap |
| 9-11 | Industry-wide adoption trends | DerivSource updates, ISDA IQ articles |
| 6-8 | General CDM/DRR overview | Factsheets, FAQ documents |
| 3-5 | Supporting technical documentation | Model docs, function specs |
| 1-2 | Tangentially related | Training, governance |
| 0 | No strategic relevance | Logos, templates, licenses |

### Executive Summary Themes Checklist:
- [ ] US Tier 1 bank strategies (JPMorgan, Goldman, Citi, BofA, Morgan Stanley)
- [ ] Production implementation evidence
- [ ] Three strategic postures (Native, Post-trade, Reporting-Layer)
- [ ] DRR regulatory compliance benefits
- [ ] Economics of adoption (cost savings, efficiency gains)
- [ ] Regulatory pressure and enforcement
- [ ] Standard evolution and jurisdiction expansion
- [ ] Smart contract/tokenization readiness

## Dimension 2: Information Quality (0-25 points)

**Evaluate source credibility and specificity:**

| Points | Criteria |
|--------|----------|
| 23-25 | Primary source + named institutions + quantitative data + direct quotes |
| 20-22 | Primary source with specific implementation details |
| 17-19 | Secondary analysis with attributed quotes/sources |
| 14-16 | Industry report with some quantitative data |
| 11-13 | General industry overview with some specifics |
| 8-10 | Overview content with limited specifics |
| 5-7 | Marketing/promotional content |
| 1-4 | Generic description |
| 0 | Boilerplate, templates, or duplicates |

### Quality Indicators Checklist:
- [ ] Named institutions mentioned (+3)
- [ ] Specific dates/timelines provided (+2)
- [ ] Quantitative metrics (%, $, time) (+3)
- [ ] Direct quotes from practitioners (+2)
- [ ] Regulatory citations (+2)
- [ ] Implementation details (+2)
- [ ] Attributed sources (+1)

## Files to Exclude from Scoring

The following file categories should be automatically excluded (Score = 0):

### 1. Versioned Duplicates (~127 files)
- All files in `website/versioned_docs/version-5.13.0/`
- All files in `website/versioned_docs/version-5.20.0/`
- Keep only `/docs/` originals or `version-6.0.0/` if newer

### 2. GitHub Templates (~15 files)
- `.github/ISSUE_TEMPLATE/*.md`
- `.github/pull_request_template.md`
- `CODE_OF_CONDUCT.md`

### 3. License/Legal Files (~10 files)
- `LICENSE.md`
- `NOTICE.md`
- `license-terms*.md`
- `EASYCLA_CHANGEME.md`

### 4. Technology Internal Docs (~60 files)
- Rune DSL internal documentation (`.junie/xtend-docs/`)
- VSCode extension quickstarts
- Tutorial basics (Docusaurus templates)

### 5. Asset Files (~5 files)
- Logo PDFs
- Duplicate overview PDFs

## Usage Instructions

1. **Quick Triage:** Use automated keyword scores to identify top 30 candidates
2. **Deep Scoring:** Apply full 5-dimension scoring to top 30 files
3. **Extract Insights:** Document key quotes, data points, and citations
4. **Gap Mapping:** Cross-reference against gap checklist
5. **Prioritize:** Focus on Score 80+ documents for immediate incorporation
