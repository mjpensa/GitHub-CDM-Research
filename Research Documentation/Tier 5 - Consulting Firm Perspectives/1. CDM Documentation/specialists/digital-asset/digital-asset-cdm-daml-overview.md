# Digital Asset: CDM and DAML Integration

**Source:** Digital Asset, ISDA
**Classification:** Technology Integration

---

## Overview

Digital Asset is a blockchain technology company that has partnered with ISDA to develop CDM implementations using DAML, their smart contract modeling language.

---

## DAML Smart Contract Language

### What is DAML?

DAML is a smart contract modeling language that can be implemented by software developers in the context of derivatives trade management. Key characteristics:

- **Purpose:** Describe multi-party workflows
- **Function:** Automate transactions between participants
- **Status:** Open-sourced since April 4, 2019

### CDM Integration

Digital Asset built a simplified code library that allows developers to implement the CDM using DAML. This enables:
- Machine-readable standardization
- Multi-party workflow automation
- Transaction automation between participants

---

## ISDA Partnership

### CDM Code Library

Digital Asset partnered with ISDA to develop a tool helping drive adoption of the ISDA CDM. The partnership focused on:
- Simplified code libraries for CDM implementation
- DAML-based CDM expressions
- Smart contract automation

### Key Benefits

ISDA's CDM facilitates automation of complex derivatives processes:
- Scheduling derivatives payments
- Applying date adjustments
- Calculating day-count fractions
- Computing interest amounts

---

## CDM Clearing Pilot

### Overview

ISDA and Digital Asset announced a pilot implementation of the Common Domain Model (CDM) for the clearing of interest rate derivatives using DAML.

### Pilot Features

The pilot takes the CDM model for clearing and adds new features:
- **Signing of state transitions**
- **Data ownership**
- **Privacy elements**

These elements are inherent within DAML as features with native support.

### Participating Organizations

| Organization | Role |

## Open Source CDM Smart Contracts (2019)

In 2019, Digital Asset open sourced a set of CDM smart contracts developed using its DAML smart contract language.

### Industry Impact Estimate

During this period, it was estimated that the CDM could save the industry $2.5 billion if combined with blockchain technology.

---

## Technology-Agnostic Design

### CDM Design Philosophy

When CDM was formulated in 2018 and 2019, there were deliberate efforts to be technology-agnostic as it was intended for use beyond blockchain.

This means CDM can be implemented on:
- Traditional systems
- Distributed ledger technology (DLT)
- Cloud platforms
- Various programming languages

## Current Developments

### Smart Contract Framework Taskforce

ISDA and Tokenovate (2025) launched a taskforce within FINOS to develop a smart contract framework within the CDM. This continues the work initiated with Digital Asset's DAML integration.

### Interest Rate Derivatives Market Size

The total notional value of all outstanding interest rate contracts was $548 trillion at the end of 2024, demonstrating the scale of potential CDM/smart contract impact.
